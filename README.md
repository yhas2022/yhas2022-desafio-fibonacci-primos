## 📚 Fundamentos Matemáticos Implementados

### 1. Sucesión de Fibonacci
Definida matemáticamente por la recurrencia:
$$F_n = F_{n-1} + F_{n-2}$$
con valores iniciales $F_1 = 1, F_2 = 1$. Se implementa mediante un bucle de permutación de variables flotantes en caliente, calculando la escala de incremento exponencial de recursos financieros sin usar vectores.

### 2. Estructura de Primalidad
Un número entero $p > 1$ es primo si y solo si sus únicos divisores positivos son $1$ y $p$. El algoritmo aplica el operador matemático de residuo (`%`) dentro de un rango acotado para auditar la resistencia de llaves criptográficas criptoseguras.

## 🛠️ Estructura del Repositorio Modular
* **`index.html`:** Dashboard interactivo con imágenes responsivas de introducción.
* **`paginas/fibonacci.html`:** Simulador dinámico del setlist de reproducción financiera.
* **`paginas/primos.html`:** Consola de juego interactivo (Escape Room) de ciberseguridad.
* **`paginas/combinado.html`:** Módulo analítico cruzado para el escaneo de coordenadas VIP.
* **`css/estilos.css`:** Maquetación global basada en CSS Grid, Flexbox y alertas de estado dinámicas.
* **`js/script.js`:** Lógica de negocio interactiva controlada estrictamente por `document.getElementById()`.
