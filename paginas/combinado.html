📋 Contexto del Problema Real

El Problema: Las bases de datos masivas contienen millones de registros planos mezclados que causan sobrecarga de procesamiento analítico humano.

La Solución: Este módulo emula un filtrado predictivo buscando comportamientos específicos (primalidad) dentro de progresiones biológicas estandarizadas (Sucesión de Fibonacci), aislando los asientos críticos VIP de un estadio de forma automatizada.

⚙️ Explicación Científica del Algoritmo

El motor ejecuta un bucle iterativo anidado sin usar vectores para optimizar la caché.

1. Serie de Fibonacci: Se calcula sumando los dos números anteriores ($F_n = F_{n-1} + F_{n-2}$) partiendo de $0$ y $1$.
2. Filtro de Primalidad: Cada número generado es transferido a un sub-bucle interno que analiza si posee exactamente dos divisores en todo el universo de números enteros. Si pasa ambas pruebas, se cataloga como Hito VIP.
